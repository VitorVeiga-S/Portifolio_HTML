# Portfólio Web

Projeto desenvolvido como atividade prática do curso de Desenvolvimento de Sistemas do SENAI, com o objetivo de criar uma página de Portfólio/Currículo Web utilizando HTML5 semântico e CSS.

## Sobre o projeto

A atividade consiste na criação de uma página de portfólio pessoal seguindo a estrutura apresentada no modelo proposto. A página reúne informações pessoais, habilidades, projetos realizados e um formulário para contato.

O desenvolvimento foi feito com foco na organização da estrutura HTML, utilização de elementos semânticos e reprodução dos principais componentes solicitados na atividade.

## Estrutura da página

A página foi dividida nas seguintes partes:

- **Cabeçalho:** contém o nome e cargo, além do menu de navegação.
- **Sobre Mim:** apresenta uma foto de perfil, informações sobre a formação e uma lista de habilidades.
- **Meus Projetos:** apresenta uma tabela com os projetos, tecnologias utilizadas, status e links para os respectivos repositórios.
- **Entre em Contato:** contém um formulário com campos para nome, e-mail, assunto e mensagem.
- **Rodapé:** apresenta os direitos autorais e informações de contato por e-mail e telefone.

## Tecnologias utilizadas

- HTML5
- CSS3

## Recursos implementados

O projeto utiliza elementos semânticos do HTML5, como `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`.

Também foram utilizados:

- Links internos para navegação entre as seções da página;
- Tabela estruturada com cabeçalho e linhas de dados;
- Formulário organizado com `<fieldset>` e `<legend>`;
- Campos de entrada, lista suspensa, área de texto e botão de envio;
- Links externos para os projetos hospedados no GitHub.
